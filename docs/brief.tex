\section*{1. Core Differentiator}
Playing unseen DOOM levels under the \texttt{doom\_env} contract requires multi-room exploration, door interaction, keycard backtracking, and combat across 525--1,050 decisions per map, with no global coordinates and a strict $\approx 40\text{ ms}$ per-decision compute budget on 1 CPU thread.

Instead of encoding raw $160\times 120$ RGB/depth pixels with a heavy CNN, our policy operates purely on the structured ego-centric signals exposed by the wrapper:
\begin{itemize}
  \item \textbf{64 ego-centric rays} (normalized distance in $[0,1]$ up to $1024$ units and 6 discrete hit types: \texttt{none}, \texttt{wall}, \texttt{door}, \texttt{locked\_door}, \texttt{enemy}, \texttt{item}).
  \item \textbf{Up to 32 visible entities} (distance, $\sin/\cos$ relative angle, relative forward/right velocity, and 12 coarse entity classes).
  \item \textbf{17 vitals scalars} (health, armor, weapon/ammo counts, 6 key flags, and ego-frame velocity).
\end{itemize}

\textbf{Differentiator:} Compact geometric encoders feed a $256$-unit GRU trained from scratch with recurrent PPO. Every action is emitted directly by the neural policy---with zero hardcoded rule trees, zero A*/Dijkstra path planners, and zero \texttt{atan2} aiming. \emph{(V1 target: ego-centric $\sin/\cos$ odometry grid and landmark slots if stabilized before G2.)}

\section*{2. Model Architecture (\texttt{submission/model.py})}
\begin{itemize}
  \item \textbf{Ray Encoder:} $16$-d \texttt{hit\_type} embeddings concatenated with normalized ray distances ($17$ channels), processed via two strided 1D convolutions (\texttt{k=5, s=2}, $32\to 64$ channels) and linear projection to $128$-d.
  \item \textbf{Entity Encoder:} $16$-d type embeddings + $5$ kinematic features $\to$ 2-layer $64$-d MLP, aggregated over valid slots (\texttt{mask}) via concatenated masked mean- and max-pooling ($128\to 64$-d).
  \item \textbf{Vitals Encoder:} Domain-normalized 17 player scalars $\to$ 2-layer $64$-d MLP.
  \item \textbf{Fusion, GRU \& Heads:} Concatenated $256$-d features $\to$ \texttt{Linear+LayerNorm+ReLU} $\to$ $256$-unit \texttt{GRU} $\to$ \texttt{MultiBinary(9)} Bernoulli actor head and scalar critic head. \texttt{DoomAgent.reset()} zeros the GRU hidden state before every map and enforces \texttt{torch.set\_num\_threads(1)}.
\end{itemize}

\section*{3. Training, Reward Shaping \& Curriculum}
\begin{itemize}
  \item \textbf{Custom Recurrent PPO (\texttt{train/ppo.py}):} Implemented from scratch with GAE ($\gamma=0.99$, $\lambda=0.95$), clip $\epsilon=0.2$, \texttt{rollout\_len=128}, $4$ epochs, \texttt{lr=3e-4}, orthogonal init, and sequence evaluation with \texttt{done} masks.
  \item \textbf{Privileged Reward Shaping (\texttt{RewardShaper}):} True position and game variables from \texttt{env.privileged\_state()} feed only training rewards; the policy never sees privileged inputs.
  \item \textbf{Reward Events:} Exit ($+10$), keycard ($+3$), enemy kill ($+1$), new $64\times 64$ cell ($+0.05$), damage ($-0.01$/HP), death ($-3$), step ($-0.001$).
  \item \textbf{5-Stage UDMF Curriculum (\texttt{train/mapgen.py}):} (1) Open rooms/corridors, (2) combat arenas, (3) multi-room doors, (4) keycard + locked door chains, (5) mix of Stages 1--4 and Freedoom 2 training maps (6 Freedoom 2 maps strictly held out).
\end{itemize}
